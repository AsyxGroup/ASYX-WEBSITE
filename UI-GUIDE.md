# ASYX Group Website UI Guide

The interface uses the visual language of the 2026 company profile: deep corporate blue, ASYX red, purple accents, white space, rounded cards, restrained gradients, and technology imagery extracted from the supplied profile.

## Primary brand palette
- Corporate blue: `#0D2741`
- ASYX red: `#DF1F3D`
- Purple accent: `#8F225D`
- Copper accent: `#AD6235`
- Light neutral: `#F5F6F8`

## Main routes
- `/` Home
- `/services` Core service pillars
- `/services/[slug]` Individual capability pages
- `/technology` Integrated solutions
- `/clients` Sector experience
- `/about` Corporate overview, vision, mission, values and governance
- `/contact` Corporate contact
- `/request-quote` Consultation request
